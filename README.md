## Organização

Os projetos deste portfólio seguem alguns princípios:

* Projetos são organizados por área técnica.
* Cada projeto possui seu próprio repositório.
* Os repositórios devem conter documentação própria.
* Laboratórios devem registrar objetivos, ambiente, configuração, testes e resultados.
* O portfólio é atualizado conforme novos projetos e estudos são desenvolvidos.
